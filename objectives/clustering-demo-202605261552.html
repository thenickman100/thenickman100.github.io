selection & strength ▼
Similarity metric
How tag overlap between two objectives is converted into a numeric edge weight (0–1). Higher = stronger, more opaque edge and stronger spring force.
Jaccard
|shared| / |total unique|. The standard balanced metric. Best general-purpose starting point.
Dice
2|shared| / (|A|+|B|). Weights shared tags more heavily — useful when the overlap itself matters most.
Cosine
|shared| / sqrt(|A|x|B|). Less sensitive to big differences in total tag count between objectives.
Overlap
|shared| / min(|A|,|B|). Fraction of the SMALLER tag set covered. A focused 3-tag objective sharing all its tags with a broad 20-tag one scores 1.0.
Resource Allocation
Sum of 1/degree(tag) for shared tags (normalised). Rare shared tags count far more than ubiquitous ones — surfaces niche thematic connections.
Adamic-Adar
Sum of 1/log(degree(tag)+1) for shared tags (normalised). Like Resource Allocation with a softer logarithmic penalty.
kNN union / mutual / Threshold
kNN union draws an edge if either node ranks the other in top-k. Mutual requires both. Threshold draws all edges at or above the similarity cutoff.
forces & physics ▼
alpha — simulation activity
What is alpha?
Think of it as the simulation's "temperature." High alpha = nodes moving rapidly toward their equilibrium. As alpha decays to zero the layout freezes.
Alpha bar
The bar shows the current alpha level. Click it to snap alpha to zero and instantly freeze the layout.
Checkbox
Unchecking disables alpha decay, locking the simulation at its current energy indefinitely.
collide — prevent overlap
Strength (0–1)
How aggressively nodes push each other apart. 0 = off, 1 = full separation enforced every tick.
Radius (rel)
Collision radius as a multiple of node radius. 1.0 = nodes just touch. 2.0 = nodes keep a full-radius gap between them.
Iterations
How many collision-resolution passes happen each tick. More iterations = tighter overlap prevention but slower simulation.
charge — attract / repel
Strength
Negative values repel nodes (default: −30). Positive values attract all nodes toward each other like gravity.
Distance min
Prevents extreme forces when two nodes are nearly on top of each other.
Distance max
Charge force is ignored beyond this radius. Lower = more local feel; higher = stronger global spreading effect.
link — edge spring forces
Base strength
How firmly edges enforce their target length. Strength scales with similarity, so strongly-similar pairs pull harder.
Base distance
The rest length for low-similarity edges. High-similarity pairs automatically get a shorter rest length (≥10 px).
Iterations
Number of constraint-solving passes per tick. More iterations = stricter link lengths, at the cost of simulation speed.
